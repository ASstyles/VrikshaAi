# **App Name**: VrikshaLife

## Core Features:

- Prakriti Analyzer: A 30-question test to determine the user's Vata/Pitta/Kapha score and personalized constitution.
- Personalized Dashboard: Displays the user's constitution, simple explanations of the score, and plant recommendations.
- Digital Herbarium: A database of 50 key medicinal plants with high-quality images, local names (5 languages), traditional uses, simple science validation, and safety warnings.
- Plant Matcher: Recommends 3 plants based on the user's prakriti, dominant dosha, health concerns, season, and availability.
- Basic Search: Allows users to search plants by name/local name, filter by health concern, and save favorites.
- Plant Identification: Identifies common Indian medicinal plants (30) from camera/upload photos, showing name and key uses immediately. Includes a tool which may filter results depending on plant location, lighting and image clarity
- Daily Wellness Tips: Provides personalized daily/weekly tips based on the user's prakriti and current season, including simple Ayurvedic rituals.
- Chatbot: An AI-powered chatbot to answer user questions about plants, doshas, and Ayurvedic principles.

## Style Guidelines:

- Background color: Light beige (#F5F5DC), evoking a natural and calming Ayurvedic feel.
- Primary color: Earthy green (#8FBC8F) to represent plants, health, and nature.
- Accent color: Warm orange (#E9967A), analogous to the green, will be used for highlights and calls to action.
- Body: 'PT Sans', sans-serif for modern readability.
- Headline: 'Alegreya', serif for an elegant, intellectual feel.
- Use plant illustrations/icons to represent different plants and doshas. Simple, clean style.
- Mobile-responsive design with a clean and informative user dashboard. Focus on clear presentation of prakriti results and plant profiles.
- Subtle transitions and animations to enhance user experience without being distracting.
